
# Diwali Community Wish — Enhanced

This is a multi-file static Diwali wish site ready for GitHub Pages.

## Features
- Animated Diyas, floating lanterns, gentle fireworks and soothing glow.
- Community chain: create a link with names encoded in the URL and share it.
- Background music toggle (place `assets/diwali_soft.mp3` to enable).
- Responsive and accessible design.

## Deploy
1. Upload the entire folder to a GitHub repo.
2. Enable GitHub Pages (use `main` branch and root folder).
3. Optional: add a `assets/diwali_soft.mp3` to enable background music.
